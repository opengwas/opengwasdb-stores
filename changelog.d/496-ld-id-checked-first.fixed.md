- **`ld-stores build` and `ld-stores import` refuse an invalid `--ld-id` before anything runs (#496).** An id that is not `OGL-` and five digits, such as `OGL-1`, used to run the whole build or import before the record writer refused it at the end. The recipe also reads its own command line as the engine does, so an input given as `--flag=value` is checked like `--flag value`, and `ld-stores rebuild` refuses while a record under `stores/ld/` cannot be read, instead of skipping it and leaving that record's Store unprotected.
