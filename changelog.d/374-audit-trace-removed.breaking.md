- **`python3 -m ogstores.audit trace` is removed, and `attribute` no longer writes a seeded sample (#374, epic #371, removed under #428).** The epic closed on 1 Nov. `trace` replayed `opengwasdb.build.row_admission.admit_rows`, which opengwasdb 0.5.0 removes. From 0.5.0 on, every build writes an Association Admission record beside its Store that counts every dropped row and logs it by source key, so the trace's question is answered by the build itself. Only `trace` read the sample, so `attribute`'s `--sample-output`, `--seed` and `--sample-per-stratum` options are gone too, and its report moves to `ogstores.audit.attribute/2`, which has no `sample` and no `scope.skipped`. `reconcile` is unchanged. The engine-imports baseline loses the 11 engine imports only `trace` and the sample used. The trace's OGS-00011 measurements stay in `docs/spec/store-audit.md` as history.
