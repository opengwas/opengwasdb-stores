- **A published `0.3.0` Observed-Only Store completes under its own id, rebuilt or converted (#527, ADR 0037 amended).** `0.3.0` joins the formats a completion parent may have (`runtime.WRITABLE_FORMAT_VERSIONS`), and a release `publish-rewrite` published is held to the records of the release it converted plus a readable `rewrite-release` record that names its Store, and one that records `variant_table.indel_order` is refused until it is rebuilt from source. A `0.2.1`-or-older parent is still refused.
