- **`publish-rewrite` accepts a warning as a conversion's deviation only when its message carries the conversion's note, and lists `variant_table.lifted_contig` (#525, ADR 0042 amendment, opengwasdb#504).** The engine's `Rule.finding` appends `[a deviation recorded by ogdb rewrite-release --convert-legacy, which converted this release from format_version <v> (release <id>); a rebuild from source fixes it]` to a finding it lowers to a recorded deviation. A rule's finding that no deviation records can be a plain warning (`lifted_contig`'s "N not judged" is one on every release), so the rule alone no longer proves it. A release converted before #504 therefore refuses its plain `lifted_contig` warning. The same applies to the other three rules.
