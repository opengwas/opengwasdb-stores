- **The engine update now requires format 0.2.3, and the docs say what 0.2.3 changes (issue #487, opengwasdb#338, ADR 0068).** `ogstores.runtime.REQUIRED_FORMAT_VERSION` is `0.2.3`, so `pixi run engine-update` refuses an engine that writes `0.2.2` or below, and `WRITABLE_FORMAT_VERSIONS` is `0.2.2` and `0.2.3`, since a `0.2.2` source completes to `0.2.3`. `docs/runtime.md`, the Analysis Catalog spec, the release metadata schema and the query walkthrough document the store-only `analyses.tsv` column `n_missing_se_out_of_range` and that from 0.2.3 no query returns a `+inf` SE.
