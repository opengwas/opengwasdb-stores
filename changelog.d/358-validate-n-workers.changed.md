- **The planned `validate` step passes `--n-workers` (stores#358, opengwasdb#315).** The count is the release's declared `n-workers` build option (a completion phase's `completion-validate` takes the `complete` block's count first), so a Dense Store's band pass runs across that many forked workers and reports the same verdict as one process. A release declaring no count plans no flag and validates with one worker as before; a count that is not a positive integer is refused. Of the committed releases, the planned `validate` argv changes for those declaring a count (OGS-00003, -08, -09 among them); no Store-writing step's argv changes.
