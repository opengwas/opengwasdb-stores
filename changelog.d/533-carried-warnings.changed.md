- **`publish-rewrite` accepts a warning the replaced Validation Record already carried unchanged (#533, ADR 0042 amendment).** The warning's message must equal one of the replaced record's `warnings` (once per recorded copy); a new warning, or one with a different Analysis or count, is still refused, as is every error. The accepted warnings are named in the Validation Record's `rewrite.carried_warnings`, beside `deviations`. This lets OGS-00011's rewrite (#499) publish with its native `eaf_orientation.unverified` warning. The post steps added to a rewritten release (#528's route) accept its `rewrite.carried_warnings` the same way.
