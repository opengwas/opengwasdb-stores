- **The `opengwasdb` engine moves from `v0.6.0` (`4b72e2f`) to `v0.6.2` (`64b5bd0`), the merge of opengwasdb PR #389.** The Store format stays 0.2.0, so the release guard's `REQUIRED_FORMAT_VERSION` does not move. `complete-ragged` now codes a residual-SE Store's cells against the source's `se_coefficients` instead of refitting them, so every observed SE comes through completion exactly and the strict Ragged Observed-View Check passes such a pair (opengwas/opengwasdb#301). That unblocks completing OGS-00006 under its own id (#224). A completed Ragged Store's manifest also records `provenance.completion.se_exceptions`: each Analysis's SE exception rate, and the Analyses over the 2% budget, which completion names in a warning. `docs/runtime.md` and ADR 0037 no longer say completion refits SE.
