- **`audit-store reconcile` no longer fails every Reference-Completed Hybrid on its Dense axis (#544).** A completion's Dense axis is the construction reference plus the LD panel's variants (ADR 0037), but the audit demanded the Dense Component equal the reference, so OGS-00011's completed Store reported `panel_partition_disagrees_with_reference` and `reference_overlap_disagrees_with_panel`. For a `reference_completed` Store it now requires the reference to be a subset of the Dense axis (`reference_rows_not_dense` and `reference_alids_missing_from_axis` both 0, else an error) and reports the extra Dense rows as the finding `dense_rows_beyond_reference`. When `records/complete.json` logs the completion's new-panel count, the extra rows must match it. An Observed-Only Hybrid keeps the exact-equality check. Closes #544.
