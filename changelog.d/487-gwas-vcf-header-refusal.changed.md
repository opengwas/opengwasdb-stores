- **The ukb-b README says that a GWAS-VCF whose header has no usable effect tags is refused (issue #487, opengwasdb#363, ADR 0076's 18 Nov addendum).** The reader refuses a header declaring neither `EZ` nor both `ES` and `SE`, naming the file and the tags it found, where it used to read an Analysis with 0 associations. All 2,514 ukb-b sources declare `ES`, `EZ` and `SE`, so no Store here is affected.
