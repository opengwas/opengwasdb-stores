- **The Ragged SSF recipes drop `stored-effect-scale`, which the engine removed (issue #487, opengwasdb final fix for epic #347).** `build-ragged-ssf` no longer takes `--stored-effect-scale`: each manifest row declares its own scale, and a missing or unknown one is refused. OGS-00006, OGS-00007, OGS-00024, OGS-00025 and OGS-00026 declare `sd` on every row, so their `build.yaml` options are now empty and the plan goldens lose the flag. Every builder also refuses an `sd` row unless its `original_sd_method` is a rescaling method or `declared_standardised`. `original_sd` is documented as required for a rescaling method. No published Store changes.
