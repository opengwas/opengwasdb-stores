How this page was made

Code
300 source files at origin/main of opengwasdb (2ef556c) and opengwasdb-stores (766faa9): every one claimed by exactly one component; no claim that matches nothing.
Imports
114 component-to-component edges from the code's imports. Inside the engine, 90 edges; 13 pairs of components import each other, and through them every engine component can reach every other. Against the declared layering, 16 edges carrying 32 imports go upward. The registry imports 13 of the engine's 15 components directly.
Decisions
107 ADRs across both repositories; 56 placed on a component, by the code they cite (68), a glossary term in their title (19), or a term used four or more times (39). The other 51 cite neither.
Work
16 open epics on the project board with 141 tickets, their blocking edges and the file paths their texts cite; 29 branches with commits not on main in the last 21 days (22 of them local to the build host, as orchestrate lanes are).
Limits
A ticket that names no file shows no work. A branch counts once it has a commit, however old its ticket. A path cited in prose counts the same as one a ticket will change. Glossary terms place an ADR by its subject, so review those placements.
