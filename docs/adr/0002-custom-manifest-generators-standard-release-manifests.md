# Custom manifest generators with standard release manifests

Each Store Family may use its own Manifest Generator because upstream sources and inclusion logic are heterogeneous across OpenGWAS VCF, BESD-like, GWAS-SSF, molecular QTL, and derived sources. The registry standardises the Release Manifest emitted by those generators so accepted releases remain comparable, reproducible, and auditable across Store Families.
