Pipeline

The path data takes through the system, from a source file to a query: the stages, the components that do each one in both repositories, and the architecture decisions (ADRs) that govern them.

See also Structure and health.

Written by hand: the stages and their order, which stages each component serves, each component’s name, summary and the code paths it claims. Each is in a repository’s docs/architecture/components.yaml.

Measured: each component’s code size, the ADRs placed on it (by the code an ADR cites and by component names in its title), and the engine commit read. Nothing measured is written by hand, so it cannot drift from the code.
