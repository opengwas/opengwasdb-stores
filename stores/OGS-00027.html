Release notes

The full eQTLGen cis-eQTL catalogue on the shared Manifest Generation pipeline: all 19,250 probes (genes) of the 2019 whole-blood meta-analysis, with ancestry measured from the BESD source’s own allele frequencies. A Ragged Observed-Only candidate.

Every probe of the genome-wide BESD file set, one Analysis each. The Store is read from the subset writer’s file set for all 19,250 probes, not from the original bytes: it has the original’s 19,250 probes and 127,339,354 associations, and 8,932,823 SNPs against the original’s 8,932,843, because the writer keeps only SNPs a probe references (20 are unreferenced) and renumbers the index. The original’s sha256 and counts are the acquisition lineage. The source is on GRCh37 (hg19); the Store is GRCh38, lifted through liftover-hg19-to-hg38. Ancestry is measured by Analysis Resolution. The SD is declared, not estimated: eQTLGen’s beta and SE are z-standardised with each SNP-gene pair’s own N (b = z / sqrt(2p(1-p)(N + z^2)), se = 1 / sqrt(2p(1-p)(N + z^2))), so SD is 1 by construction and the original_sd cell stays blank, as for every declared_standardised tier. An estimated SD would only measure sqrt(31,684 / pair N): 29% of a 200-probe trial exceeded 1.5, and TNF’s 2.04 is an N of about 7,600. Each Analysis’s sample_size is the maximum of its probe’s published per-pair N (the NrSamples of the published cis-eQTL file, read from the sample-size table below), so it equals the maximum of the Store’s own n plane and is never recovered from the BESD. 5,465 of the 19,250 probes (28%) have a pair at the study total of 31,684, measured in the study’s full cohort set; the rest were covered by fewer cohorts (minimum 232). sample_size_kind is variant_level. Per-association N is stored: each stored (probe, SNP) pair carries eQTLGen’s published NrSamples (opengwasdb#302, ADR 0067), joined from the published cis-eQTL file by a sample-size table aligned to this file set; a pair the published file lacks is missing, never estimated. The Analysis-level sample_size above is that same maximum, so the two agree. The .esi allele frequency is stored per association too, oriented to the effect allele and checked once against the UK Biobank “United Kingdom” frequencies (ukb-ancestry-mixture-hg38-uk-eaf), never an hgdp1kgp-hg38 panel. The reference is a single table, so no eaf-reference-ancestry is passed: opengwasdb ignores it for a table, and the population is the table’s column (United Kingdom). SE stays float16 beside the n plane (ADR 0067 section 4). The study is Võsa et al., Nature Genetics 2021 (PMID 34475573, DOI 10.1038/s41588-021-00913-z), published at https://eqtlgen.org/cis-eqtls.html; each Analysis is labelled with eQTLGen’s published gene symbol (connectors/gene-symbols.tsv, from the published cis-eQTL file: all 19,250 probes have one), while its id stays the bare Ensembl id.

Candidate status: human review required before acceptance (issue #153). 19250 included, 0 excluded of 19250 frozen inventory rows.
