Release notes

Full dense Store Release of all 2,514 UK Biobank (ukb-b) GWAS-VCF Analyses declared in the OpenGWAS IGD collection and verified present in /data/opengwasdb/raw/gwas-vcf/ukb-b, reference-completed under its own id against the UKB EUR LD panel (ADR 0037).

Membership is the frozen Source Inventory ukb-b-restored-2026-10-11: 2,514 Analyses, each with a recorded sha256, size and mtime. It replaces the incomplete 2,024-Analysis candidate previously registered under this id, adding the 490 Analyses that candidate was missing and removing none; its two-id completed child OGS-00010 is retired, as are the successor ids OGS-00030/31 #219 reserved (#312). The Store is built observed-only, then completed against the UKB EUR LD panel (ukb-hg38-eur-ld) and replaced under the same id once the observed-view check passes. Analytical Metadata is resolved from each Analysis’s provider JSON sidecar (exact-ID checked, batch checked, sha256-bound); that resolution agrees with the recorded opengwas-api-r2026-08-10 resolution on every one of the 2,511 rows it covered and supplies the three rows it had left unresolved. Ancestry is the provider’s own population label (source_fallback), not an AF-based assignment; the ukb-b VCFs do carry FORMAT/AF, so the historical source_trusted_no_af value is not reproduced. The owner accepted these source labels (all EUR) for this build, with no AF assignment first (#312, 2026-10-21). Pre-release SE codec re-encode (2026-10-25, #326): under the one-time exception authorized before the project’s first release, only the `se` and `se_exception_index` Blosc `typesize` values and encoded chunk bytes changed. `records/se-reencode.json` reports full-array decoded equality across 447,689 chunks and 2,810,059,224 bytes saved; the post-run Store validation and observed-view check passed. This physical-representation-only exception sets no precedent after release.
