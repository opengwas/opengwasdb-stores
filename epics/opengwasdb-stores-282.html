Epic: Manifest Generation as one pipeline fed by source connectors

Purpose

Design: ADR 0036 (#281).

Epic #282 moved Manifest Generation onto one shared pipeline fed by per-source connectors (ADR 0036). It merged in three stages: PR #299 on 21 October, PR #342 on 22 October and PR #365 on 28 October. Stage 3 moved GWAS Catalog metadata interpretation into its connectors, took Canonical Trait Mapping curation off the last two R ontology helpers, and added a per-association sample size plane so that OGS-00027 stores its own N. OGS-00027 was rebuilt with that plane and marked validated.
