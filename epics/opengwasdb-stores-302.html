Single-id reference completion: completion replaces its Store under the same id

Purpose

Today a reference-completed Store needs two Store Releases. The Observed-Only Store is built and published under one id, and reference completion then derives a second Store Release under a new id, linked by `derived_from` (ADR 0007).

Epic #302 made reference completion replace its Store under the same id (ADR 0037), so one Store Release is built Observed-Only and then completed in place instead of becoming two ids. It added single-id Dense completion in one run, completion of an already-published Observed-Only Store later, an observed-view check that gates the swap, and deletion of the replaced Store at the swap. The master list reports the Store actually published, and Manifest Generation emits single-id completed bundles. It merged as PR #311 on 21 October.
