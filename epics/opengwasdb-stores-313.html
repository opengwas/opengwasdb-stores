Epic: Analysis catalog across all Stores

Purpose

The API, the website and the R and Python clients (opengwas/opengwasdb#93, #94) need to find every Analysis across every Store Release. No single listing exists today. Each built Store carries its own `analyses.tsv`, and the Store Registry carries the Release Bundles. Several questions have no recorded answer:

Epic #313 adds the Analysis Catalog: a versioned SQLite listing of every Analysis in every validated Store, built by `pixi run catalog` from the registry’s Release Bundles. Its first phase (PR #328) added the catalog package, search and counts, the summary report, and the trial and superseded_by fields of the Release Bundle. Its second phase (PR #353) gave Association Coverage one vocabulary declared in the Release Bundle, marked OGS-00027 validated, and published the catalog; version 1b3a155d449bb84a lists 9 Stores and 31,940 Analyses. The epic stays active because OGS-00011 is not validated, so the catalog does not list it.
